## Important Details
- `htmlToADF` is a **global** from classic script `libraries/jira-adf.js` (popup.html line ~206), loaded before the `popup.js` module; new modules use the bare identifier.
- Uploads use `XMLHttpRequest` (not fetch) via `xhrUpload` in api.js (upload progress + abort); normalized to `{ok, status, data}`.
- Jira Cloud rejects ~25 MB+ attachments (JRACLOUD-75756); **cutoff is now 26 MB** (`MAX_ATTACHMENT_UPLOAD_BYTES = 26 * 1024 * 1024` in ui.js) because a 25 MB file can round up and upload fine — note still says "over 25 MB skipped — add them from the Jira UI.".
- ServiceNow Table API auth: needs the page's session cookie plus CSRF `X-UserToken` (from `window.g_ck`, meta, or hidden input) and must run in the **MAIN world**; isolated-world fetch triggers a 401 Basic-auth dialog that JS can't suppress.
- Spark attachment sizes come from `/api/now/table/sys_attachment?sysparm_fields=file_name,size_bytes&sysparm_display_value=false&sysparm_limit=1000`, matched to DOM rows by file name; size_bytes sometimes a numeric string (`Number(...)` to convert).
- All `...InTab` helpers that hit Spark APIs run `chrome.scripting.executeScript` with `world: siteName === "Spark" ? "MAIN" : "ISOLATED"` (`listTicketAttachmentsInTab`, `listListingAttachmentsInTab`); `scrapeSelectedSparkListingInTab` uses `allFrames: true` (list may live in a shell iframe).
- Popup body (`width: 460px`, `overflow-y: auto`, html `overflow: hidden`) is the scroll container; `switchView` preserves per-view `document.body.scrollTop` via `viewScroll = { single: 0, bulk: 0 }`.
- `equalizeInitialViewHeights()` (popup.js) measures both views' natural height (synchronously unhiding each) and pins `style.minHeight` to the tallest — runs via `applyDetectedState().then(equalizeInitialViewHeights)`.
- `gap-art.js` is multi-canvas (`scenes` for `#gapArt` + `#gapArtBulk`, the latter replacing the `.view-fill` div in popup.html); ResizeObserver + `visibilitychange` start/stop; one visible canvas paints at a time. **Regression risk noted:** it must keep `let rafId = 0;` declared or `startGapArt` throws at boot and all popup listeners die.
- User chose "On/off toggle + per-ticket picker" for bulk attachments, **default OFF**.
- **Bulk attachment selection semantics (authoritative):** `state.bulkAttachmentSelection` map (`{ [ticketId]: [names] }`) or `null`. `null` (picker never loaded / listing failed / toggle off) ⇒ include everything (defensive). When the map is present, a ticket's entry — even an empty array, or missing ⇒ empty — is authoritative: upload exactly its checked names, so a ticket with every file over the upload cap uploads none. Both Spark `fetchSparkAttachments` and Octane `fetchItem` implement this (`!selected || selected.has(name)` where `selected = map ? new Set(map[id] || []) : null`). `renderBulkAttachmentPicker` skips empty groups (⇒ no entry ⇒ upload none), which is correct under these semantics.
- Verification standard: `node --input-type=module --check < file` for syntax (use redirect form, not plain `node --check`, for popup.js/components due to web globals); VM harness `/var/folders/ck/z57vqryx22701w7p4j3cp6lc0000gp/T/opencode/octane-harness.mjs` => 38/38 PASS.
